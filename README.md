# Pokémon Meadow — 로컬 도트 생존 프로토타입

`플레이.command`를 더블클릭하면 실행합니다. 에디터에서 작업하려면 `에디터.command`를 엽니다. 두 바로가기는 상위 폴더의 `.tools/Godot.app`을 사용하므로 프로젝트만 다른 위치로 옮기면 경로를 조정해야 합니다.

## 이번에 구현한 것
- 시작 화면에서 파이리·꼬부기·이상해씨 선택. Lv.5 / Lv.9에 각 계열로 진화하며 25 회복.
- 파이리 → 리자드 → 리자몽 / 꼬부기 → 어니부기 → 거북왕 / 이상해씨 → 이상해풀 → 이상해꽃.
- 자동 공격, 경험치 수집, 레벨업 시 전투를 멈추고 기술 선택.
- 파이리: 불꽃세례·할퀴기·용의분노·화염방사.
- 꼬부기: 물대포·몸통박치기·물기·거품.
- 이상해씨: 덩굴채찍·몸통박치기·잎날가르기·오물폭탄.
- 계열별 최대 4기술, 각 5단계. 완성 후 회복 선택.
- 불꽃 대 풀·벌레 2배, 물 0.5배, 노말 대 고스트 무효 등 방어 속성을 반영. 용의분노는 고정 40.
- 3분에 팬텀 등장. 처치하면 승리, 체력 0 또는 총 4분 30초가 되면 패배.
- 일시정지·재시작·효과음 켜기/끄기·게임 내 출처 화면.

## 조작
WASD/방향키 이동, Space 회피, Esc 일시정지/계속, 기술 선택 시 1/2/3 또는 클릭. 시작 화면에서는 1/2/3 또는 클릭으로 파트너를 고르고 Enter로 출발합니다. 재시작은 선택한 파트너를 유지합니다. 공격은 자동입니다.

처음에는 풀·벌레 적을 상대로 경험치를 모으세요. 꼬부기는 불꽃에 강하므로 할퀴기나 용의분노를 함께 배우면 유리합니다. 팬텀에게 할퀴기는 통하지 않습니다.

## 파일 구조
- scripts/rules.gd: 상성·경험치·진화·기술 데이터
- scripts/arena.gd: 한 판의 전투와 상태 전환
- scripts/meadow.gd: 절차적 배경
- scripts/interface.gd, meter.gd: 화면·메뉴·표시
- assets/manifest.json: 도트별 출처·원본 버전·해시
- docs/CREDITS.md, POKEAPI-LICENCE.txt: 권리 고지와 원본 라이선스
- tests/: 규칙, 상태 전환, 한 판 시뮬레이션, 렌더링 검증

## 범위와 제한
첫 3분 전투 프로토타입입니다. 정면 도트에 움직임 효과를 적용했으며, 고품질 다방향 걷기 애니메이션은 아직 없습니다. 저장·10분 스테이지·배경음악·장애물 충돌은 구현하지 않았습니다. 나무 테두리는 이동 경계이며 연못과 표지판은 장식입니다. 조작감을 위한 난이도와 효과음은 첫 조정값입니다.

비영리 로컬 용도입니다. 원작 IP 사용 허가는 해결되지 않았으며 공개 배포나 라이선스 문제 해결을 주장하지 않습니다. 자세한 조건은 출처 화면과 docs/CREDITS.md에 있습니다.

## 검증
`tools/verify.command`로 규칙·전투 상태·한 판 자동 시뮬레이션과 렌더링 검사를 실행합니다. 화면 3장은 docs/preview-*.png에 갱신됩니다. 자동 시뮬레이션은 인간 플레이 난이도 평가나 실제 렌더링 프레임 성능 측정을 대신하지 않습니다.
