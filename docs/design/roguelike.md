# Pokémon Meadow — three-region fan prototype

Approved request: improve visual identity using classic Pokémon game references, distinct skill effects, subtle shadows and bundled Pretendard; select any National Dex species 1–386; complete three regions with bosses and random between-region rewards. Implement directly in this session and show the running result.

Presentation: FireRed/LeafGreen Pokédex and battle-menu reference (https://www.pokemon.com/us/pokemon-video-games/pokemon-firered-version-and-pokemon-leafgreen-version). Red device frame, cream inset panels, dark navy text, colored type chips, crisp nearest-filtered sprites. No borrowed UI screenshots or logos. The official gallery was access-blocked; the actual FireRed Pokédex screenshot at https://i.imgur.com/bOTIPYu.png was inspected as a visual reference, with no image bytes added to the project. Font sizes 32/24/18/14/12; Regular/SemiBold/Bold Pretendard 1.3.9 under OFL, bundled with license. Subtle ground contact shadows only; no screen flash or camera shake.

Selection: 386 species; Korean/English/dex search, generation and type filters, 18 items per page, selected details and evolution preview. Updated 2026-09-29: Only 202 base forms without a pre-evolution inside Gen I–III are selectable. Evolved sprites remain available through in-run evolution. Both catalog filtering and Arena selection/start guards enforce this. Existing 1/2/3 starter shortcuts retained outside search inputs. Evolution only advances from selected form, at custom levels 5/9; choose the first available descendant inside Gen I–III for branched lines, disclose route in selection UI. No later-gen evolution. Gen III historical typing; survival move sets are custom type-based loadouts, not canonical learnsets.

Run: Kanto forest → Johto autumn grove → Hoenn lagoon. 90-second waves then boss, 60-second boss deadline; overall roughly 5–8 minutes. Bosses Gengar/Tyranitar/Metagross. Intermediate boss victory freezes combat, removes old combat objects, offers 3 randomized distinct relics; selection grants 25 HP and advances region. HP, level, evolution, skills and relics carry forward. Final boss wins. Death/time-out resets on restart, with new random seed and region modifiers. No permanent metaprogression/save feature in this prototype.

Boundaries: Catalog owns localized species/evolution/typing. Journey owns regions/rewards. Rules owns damage/move choices. Arena owns run state/transitions. FX owns visual drawing. Interface owns selection/menu/HUD. Build no external runtime dependency; pinned source assets and data are available offline.

Validation: all 386 data/texture/loadout entries, historical typing, evolution no regression, search zero results/page clamp, all attack render variants, intermission freeze/single reward/carry/reset, first/intermediate/final boss transition, full-run normal-speed seeded simulation for 3 starter types, native input and visual captures. Existing tests updated for changed stage contract. Real-human balance and sustained performance remain separately unverified.

Rights: retain source notices and hashes. Original Pokémon IP permissions remain unresolved. Private/local fan prototype; do not claim public redistribution clearance or that noncommercial use grants permission. No public deployment. Pretendard may be bundled with its OFL notice.
